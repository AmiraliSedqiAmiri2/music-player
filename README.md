# 🎵 Music Player

A modern and responsive music player built with **HTML, CSS, and JavaScript**.

This project features a clean user interface with a dark theme, neon purple accents, and glassmorphism effects.

### ✨ Features
- Play and pause music
- Switch between tracks (Next / Previous)
- Interactive music progress bar
- Display current playback time and total duration
- Adjustable volume control
- Dynamic song titles, artists, and cover images
- Responsive and modern UI

### 🛠️ Technologies
- HTML5
- CSS3
- JavaScript
- Font Awesome

### 🎯 Purpose
Built as a personal project to practice JavaScript, DOM manipulation, event handling, and working with the HTML Audio API.
